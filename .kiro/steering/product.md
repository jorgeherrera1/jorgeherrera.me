# Product Overview

This is Jorge Herrera's personal blog - a modern, performance-focused website for sharing thoughts on web development, technology, and software engineering.

## Key Features

- Static-first architecture with component islands for optimal performance
- SEO-optimized
- Tag-based article organization and filtering
- Responsive design with consistent typography
- Syntax highlighting for code blocks
- Related articles suggestions based on shared tags

## Content Focus

The blog will cover topics related to:
- Web development trends and practices
- JavaScript and modern frontend technologies
- Software engineering insights
- Technology industry observations

## Design Philosophy

### Theme Requirements
- **RETRO theme** heavily inspired by 8-bit Super Mario Bros
- **DARK theme only** - inspired by Bowser Castle stages from Super Mario Bros
- **8-bit pixelated elements** and Super Mario Bros piece visuals expected
- **Unique design** - no other website should look like this one
- **Monospaced fonts** preferred throughout
- **Success metric**: Uniqueness of the retro theme implementation

### User Experience Priorities
- **Modern-first approach** - no backwards compatibility or polyfills
- **Latest browser features only** - older browser support not required
- **Single user focus** - optimized for the author's reading experience
- **Article readability** - proper spacing, font sizing following best practices while maintaining theme consistency

## Performance Goals

- 100/100 Lighthouse performance score
- Fast loading times through static generation
- Minimal JavaScript shipped to browser
- SEO-friendly with proper metadata and structured content
