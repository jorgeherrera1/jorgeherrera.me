Been using Orca orchestrating other terminal/agents and so far the experience has been positive overall. Having a single entry point that talks and coordinates the rest of agents is a good developer experience.

Ever since Claude Projects was announced I felt some excitement on how Claude would approach this. I expected the bar to be high, specially since they took their time to release this feature to the open. [[Cursor Projects nailed it|Cursor Projects]] is good. [[Grok Bot is cool|Grok Bot]] is good. So Claude Projects had to be good as well.

So far it is not. I haven't tested it on my desktop so hopefully mobile is a loose end for them and they will take care of it later but the experience is not good so far.

Yes, they (try to) give me a single entry point but I'm having to go to the threads myself to get answers. I don't want that. I want to deal only with the main thread. Only if I want to steer the other agents I will decide to do it.

This is an early assessment but I wanted to write about it.
