# Story 2.4: Enhanced Article Metadata

## Status: Draft

## Story

- I want to include rich metadata in my articles

### Reading Time Calculation

**Implementation Approach:** [Source: architecture/coding-standards.md#content-processing]
Create utility function for reading time estimation:
```typescript
export function calculateReadingTime(content: string): number {
  const wordsPerMinute = 200;
  const words = content.split(/\s+/).length;
  return Math.ceil(words / wordsPerMinute);
}
```

**Display Integration:** Add reading time to ArticleCard and individual article pages alongside date and tags.

### URL Generation Enhancement

**Current URL Strategy:** [Source: architecture/project-structure.md#api-reference]
Articles currently use filename-based URL generation. Enhancement should support:
- Custom slug from frontmatter when provided
- Auto-generated slug from title as fallback
- Filename-based as final fallback for backward compatibility

**Implementation:** [Source: architecture/coding-standards.md#url-generation]
```typescript
export function generateArticleSlug(article: Article): string {
  if (article.data.slug) return normalizeSlug(article.data.slug);
  if (article.data.title) return normalizeSlug(article.data.title);
  return article.id; // filename fallback
}
```

### Draft Content Handling

**Environment-Aware Filtering:** [Source: architecture/coding-standards.md#content-standards]
- Production: Exclude drafts from all public lists and pages
- Development: Include drafts with visual indicators
- Build process: Validate that drafts don't break navigation

**Implementation Strategy:**
```typescript
export async function getAllArticles(includeDrafts = false): Promise<Article[]> {
  const allArticles = await getCollection('blog');
  if (!includeDrafts && import.meta.env.PROD) {
    return allArticles.filter(article => !article.data.draft);
  }
  return allArticles;
}
```
