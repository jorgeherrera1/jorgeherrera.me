### Reading Time Calculation

**Implementation Approach:** [Source: architecture/coding-standards.md#content-processing]
Create utility function for reading time estimation:
```typescript
export function calculateReadingTime(content: string): number {
  const wordsPerMinute = 200;
  const words = content.split(/\s+/).length;
  return Math.ceil(words / wordsPerMinute);
}
```

**Display Integration:** Add reading time to ArticleCard and individual article pages alongside date and tags.

### CSS Text Truncation Implementation

**Modern CSS Approach:** [Source: architecture/tech-stack.md#cutting-edge-css]
Use modern CSS features for automatic text truncation:

**Single-line truncation:**
```css
.article-preview {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

**Multi-line truncation (line-clamp):**
```css
.article-preview {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

**Implementation Strategy:**
- Display first portion of article content directly
- Use CSS line-clamp for consistent multi-line truncation
- No JavaScript or manual description writing required
- Automatic responsive behavior based on container size
