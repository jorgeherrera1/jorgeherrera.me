# Story 2.2: Tag Display on Articles

## Status: Approved

## Story

- As a reader
- I want to see tags displayed on articles
- so that I can understand the topic categories and discover related content

## Acceptance Criteria (ACs)

- 1: Tags are displayed on individual article pages in a clear, visually distinct way
- 2: Tags are also shown on the homepage article list for quick scanning
- 3: Tags are clickable links that lead to filtered views
- 4: Tag styling is consistent with the minimal aesthetic
- 5: Multiple tags are displayed in a clean, organized manner
- 6: Tags are accessible via keyboard navigation

Story 2.1 completed the tag system implementation with full Content Collections schema, tag processing utilities, and normalization functions. ### Component Architecture

**Tag Display Component:** [Source: architecture/project-structure.md#component-structure]
Create `src/components/TagList.astro` for reusable tag display:

```astro
---
interface Props {
  tags: string[];
  showLinks?: boolean;
}

const { tags, showLinks = true } = Astro.props;
---

<div class="tag-list">
  {tags.map(tag => (
    showLinks ? (
      <a href={`/tags/${tag}`} class="tag-link">
        {tag}
      </a>
    ) : (
      <span class="tag">
        {tag}
      </span>
    )
  ))}
</div>
```

**Integration Points:** [Source: architecture/coding-standards.md#astro-component-standards]
- `src/components/BlogPost.astro` - Individual article pages
- `src/components/ArticleListItem.astro` - Homepage article previews
- Both components should use the shared `TagList.astro` component
