# Story 3.3: Homepage Card-Based Article Layout

## Status: Done

## Story

- As a reader
- I want the homepage to display articles in styled card format instead of a simple list
- so that I can quickly scan and discover content through an visually appealing, organized layout that maintains the retro aesthetic while improving content presentation

## Acceptance Criteria (ACs)

- 1: Homepage displays exactly 3 latest articles in a card-based layout instead of the current simple list format
- 2: Each article card has rounded corners, clean layout with structured content presentation
- 3: Cards maintain existing retro theme colors and typography (amber accents, monospace fonts, dark background)
- 4: Each card displays: title (as clickable link), date, reading time, content excerpt, and tags
- 5: Card layout uses responsive 3-column grid on desktop that adapts to 2-column on tablet and 1-column on mobile
- 6: Cards have subtle hover effects and interactive states that feel tactile and enhance the retro terminal aesthetic
- 7: Existing tag system and styling are preserved and integrated into the card design

### Responsive Grid System

**CSS Grid Implementation:** [Source: architecture/frontend-architecture.md#responsive-design-strategy]
```css
.article-card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(320px, 1fr));
  gap: 1.5rem; /* 24px */
  
  /* Desktop: 3 columns */
  @media (min-width: 1024px) {
    grid-template-columns: repeat(3, 1fr);
  }
  
  /* Tablet: 2 columns */
  @media (min-width: 640px) and (max-width: 1023px) {
    grid-template-columns: repeat(2, 1fr);
  }
  
  /* Mobile: 1 column */
  @media (max-width: 639px) {
    grid-template-columns: 1fr;
  }
}
```

### Retro Card Styling Guidelines

**Card Design Specifications:** [Source: architecture/components.md#styling-system]
```css
.article-card {
  /* Base card structure */
  @apply bg-slate-800 border border-slate-700 rounded-lg;
  @apply p-6 shadow-sm;
  
  /* Hover states for tactile feel */
  @apply hover:border-slate-600 hover:shadow-md;
  @apply transition-all duration-200 ease-in-out;
  
  /* Focus states for accessibility */
  @apply focus-within:ring-2 focus-within:ring-amber-400 focus-within:ring-opacity-50;
}

.article-card-title {
  @apply text-xl font-semibold mb-3 text-blue-400;
  @apply hover:text-blue-300 transition-colors;
}

.article-card-meta {
  @apply flex items-center gap-3 text-sm text-slate-400 font-mono mb-4;
}

.article-card-excerpt {
  @apply text-slate-200 leading-relaxed mb-4;
  @apply line-clamp-3; /* CSS line-clamp for consistent truncation */
}
```
