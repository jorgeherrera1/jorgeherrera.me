## Dev Technical Guidance

### Architecture Context

This story implements the foundational setup for Jorge's Knowledge Crystallization Blog as defined in the architecture document. The system uses **Enhanced Static Site Generation** with Astro.js and Tailwind CSS for optimal performance and content focus.

**Key Technical Requirements:**
- **Framework**: Astro.js (latest stable) - chosen for superior markdown processing and static generation
- **Styling**: Tailwind CSS (latest) - required for dynamic theming and utility-first approach
- **Language**: TypeScript - for type safety and development productivity
- **Content Strategy**: Markdown-driven with frontmatter metadata

[Source: architeture.md#definitive-tech-stack-selections]

### Project Structure Requirements

The project must follow this specific structure to align with the architecture:

```
src/
├── components/
│   ├── layout/          # BaseLayout, Header, Footer
│   ├── content/         # ArticleCard, ArticleList, ArticleContent
│   ├── navigation/      # TagCloud, Tag, Breadcrumb
│   └── ui/              # ThemeToggle, CodeBlock
├── content/
│   └── blog/            # Markdown articles location
├── pages/
│   ├── index.astro      # Homepage (cards)
│   ├── blog/            # Blog routes
│   └── tags/            # Tag filtering pages
├── styles/
│   ├── global.css       # @import "tailwindcss"
│   └── theme.css        # CSS custom properties
├── utils/               # blog.ts, tags.ts utilities
└── types/               # blog.ts type definitions
```

[Source: architeture.md#project-structure]

### Required Dependencies

Based on the architecture, ensure these key dependencies are installed:

**Core Framework:**
- `astro` (latest stable)
- `@astrojs/tailwind` (Tailwind integration)
- `tailwindcss` (latest version)

**Content Processing:**
- `@astrojs/content` (for content collections)
- `@astrojs/sitemap` (for SEO)

**Development:**
- `typescript` (latest)
- `@types/node` (for Node.js types)

[Source: architeture.md#technical-summary]

### Astro Configuration Requirements

The astro.config.mjs must include:

```javascript
export default defineConfig({
  site: 'https://jorgeherrera.me',
  integrations: [tailwind(), sitemap()],
  experimental: { viewTransitions: true },
  build: { inlineStylesheets: 'auto' },
  compressHTML: true,
});
```
